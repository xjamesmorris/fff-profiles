# 3DXTech CarbonX PEKK-A+CF — Core One HT0.6

Profile: [`CARBONX_PEKK-A+CF_HT0.6__PrusaCOREOne_Prusaslicer.ini`](CARBONX_PEKK-A+CF_HT0.6__PrusaCOREOne_Prusaslicer.ini)
(appears in PrusaSlicer as **3DXTech PEKK-A+CF @COREONE HT0.6 experimental**).
Experimental, uncalibrated.

## Printer setup required

This profile tags prints with filament type `PEKK-A`, which the Core One doesn't have built
in. **Before printing, create a custom filament named `PEKK-A` on the printer**, or it will
show a wrong-filament warning when you start a print.

The settings to enter (name, base preset, temperatures, abrasive flag, etc.) are listed in
[Add a PEKK-A custom filament on the printer](../../../docs/CoreOne_custom_filament.md#2-add-a-pekk-a-custom-filament-on-the-printer).

## Requirements

- PrusaSlicer 2.9.6 or newer, with Prusa system profiles 2.5.11 or newer
- Core One with the HT400 hotend, standard-flow 0.6 mm nozzle, and the high-temperature idler door

See the [full PEKK-A+CF walkthrough](../../../docs/CoreOne_custom_filament.md#worked-example-3dxtech-pekk-acf)
for import steps and the idler-door warning.
