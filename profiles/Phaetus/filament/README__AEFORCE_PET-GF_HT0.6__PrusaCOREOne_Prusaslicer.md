# Phaetus aeForce PET-GF — Core One HT0.6

Profile: [`AEFORCE_PET-GF_HT0.6__PrusaCOREOne_Prusaslicer.ini`](AEFORCE_PET-GF_HT0.6__PrusaCOREOne_Prusaslicer.ini)
(appears in PrusaSlicer as **Phaetus aeForce PET-GF @COREONE HT0.6**).

## Printer setup required

This profile tags prints with filament type `PET`, which the Core One doesn't have built in
(it has PETG, which is a different name). **Before printing, create a custom filament named
`PET` on the printer**, or it will show a wrong-filament warning when you start a print.

The settings to enter (name, temperatures, chamber, abrasive and filtration flags) are listed in
[Add a PET custom filament on the printer](../../../docs/CoreOne_custom_filament.md#2-add-a-pet-custom-filament-on-the-printer).

## Requirements

- PrusaSlicer 2.9.6 or newer, with Prusa system profiles 2.5.11 or newer
- Core One with the HT400 hotend and a standard-flow 0.6 mm nozzle

See the [full PET-GF walkthrough](../../../docs/CoreOne_custom_filament.md#worked-example-phaetus-aeforce-pet-gf)
for import steps.
